# Upscaler 16K — локальный нейросетевой апскейл

Десктопное приложение: выбираете **любое изображение** (диалог или drag&drop), получаете `<имя>_16k.png`
(длинная сторона 15360 px, пропорции сохраняются). Нейросеть — Real-ESRGAN x4plus (или SwinIR),
никакого bicubic/Lanczos для увеличения; Lanczos используется только для финальной подгонки на точный размер.
Всё считается на вашем компьютере. Интернет нужен один раз — скачать зависимости и веса.

## Запуск (macOS)
1. Двойной щелчок по `setup.command` (один раз; если macOS ругается — ПКМ → «Открыть»).
2. Далее запуск — `Upscaler.command`.

Консоль: `source .venv/bin/activate && python upscale_cli.py photo.jpg --target 16K`

## Как это сохраняет детали и идентичность
- **Тайлы + перекрытие 48 px + сглаженное смешивание** (smoothstep, нормировка весов) — швов нет
  (`python selftest.py` проверяет склейку побитово).
- Результат пишется потоком на диск, в ОЗУ — только одна полоса тайлов: 16K влезает в обычную память.
- Если исходник меньше 3840 px по длинной стороне, нужно 2 прохода ×4; потом точная подгонка до 15360.
- Ползунок **«верность ↔ детали»** — интерполяция весов Real-ESRNet (мягче, ближе к оригиналу) и Real-ESRGAN
  (резче, больше текстур). Против «пластиковой» кожи — смещайте влево (60–80%).
- **Коррекция цвета (вкл. по умолчанию):** GAN-модели слегка смещают цвет, а при 2–3 проходах ×4 сдвиг копится
  (на тёплых кадрах — красно-пурпурный оттенок). После каждого прохода и в конце крупный цвет/свет привязываются
  к источнику на сетке 4×4 px (обратная проекция), детали остаются от нейросети, JPEG-блоки не возвращаются.
  Уже готовый результат можно исправить без пересчёта: `python fix_colors.py result_16k.png original.jpg`.
- Цвет: ICC-профиль и DPI копируются; альфа-канал масштабируется отдельно; 16-бит конвертируется в 8-бит.
- Лица **не перерисовываются** (GFPGAN/CodeFormer намеренно не используются — они меняют черты).

## Нехватка памяти
Приложение само уменьшит тайл при ошибке памяти. Apple Silicon: рекомендуем тайл 384.
Время: 16K — это много пикселей; на M-серии ожидайте десятки минут (зависит от размера исходника).
